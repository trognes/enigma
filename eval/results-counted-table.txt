# eval/counted_table_ab.py 400 59  80 100 0.05,0.2,0.5   (weights, seed 59)
# eval/counted_table_ab.py 400 131 80 100 0.2            (held-out seed)
# eval/counted_table_ab.py 400 211 80 100 0.2 --garble   (garbles in)
# eval/counted_table_ab.py 400 211 {60,100,167} 8 0.2    (other lengths)
#
# Rotor key given, 10-pair board hidden, -c -f -S k4f10 -K --polish
# -l wehrmacht, -T 1.  Each order's stock table mixed with the TRAINING
# folds' n-gram counts at weight w of the table's mass; five folds by
# message; a message never contributes to its own table.  A board counts
# as recovered at >= 50%.  The captured runs were made with an earlier
# revision of the script that took the same parameters positionally; the
# trial draws and the tables are unchanged.

# READING.
#
#   cell                               base   supp   discordants    z
#   L=80  -R 100 clean, seed 59         156    185     47 / 18     3.6
#   L=80  -R 100 clean, seed 131        150    184     47 / 13     4.4
#   L=80  -R 100 all messages           164    185     49 / 28     2.4
#   L=60  -R 8                           23     32     18 /  9     1.7
#   L=100 -R 8                          114    123     44 / 35     1.0
#   L=167 -R 8                          271    282     40 / 29     1.3
#
# +8pp of break50 at L=80 and -R 100 (39% -> 46-47%), replicated on a
# held-out seed at the same size, and positive at every other cell -- the
# three -R 8 cells pool to +29 breaks of 1200 (z = 2.2), so the prior costs
# nothing at L=167 where a mistuned table would first show.  The weight
# barely matters across a 10x range (184/185/189 of 400), so w = 0.2 is
# not a tuned optimum.  With the garble-flagged messages in the pool the
# gain halves (+21 against +34), as the floor probe predicted: a garble is
# a window no table can lift.
#
# WHAT IT IS, AND IS NOT.  The folds hold out MESSAGES, not the network:
# every message is HG Nord 1941, so what transfers between folds is that
# network's vocabulary and habits -- XSIGX, XLKWX, the spelled numbers, the
# unit designations.  This is an in-network prior, the same standing the
# crib library has (83% held-out coverage within the collection), and it
# says nothing about another network's traffic.  It is also built from 34
# messages; the whole recurring vocabulary of the collection is what it
# knows.
#
# DO NOT ship it as the `wehrmacht` tables.  Every eval harness in this
# repository draws its trials from the same 62 messages, so a table counted
# from all of them would contaminate every measurement made after it.  If
# it ships at all it is a separate language built from a stated message
# set, with the evals staying on `wehrmacht`.

# clamps a count at 2^32, and log10(count / total) is scale invariant, so the

# count reached the clamp, so the earlier rows are unaffected.

# READING.  On the seed-59 trial set, break50 of 400 against a base of 156:
#
#   w      0.01  0.05  0.2  0.5   1    2    5   10   20   50  200  1000
#   breaks  170   184  185  189  188  194  201  206  207  211  213   219
#
# Monotone over five orders of magnitude, and at w = 1000 the stock table is
# only smoothing -- the corpus counts ARE the model: 39% -> 55% of messages
# broken.  Held out on seed 131, w = 5 and 10 read 200 and 198 against 150,
# the same +50.  At the other lengths w = 1000 is ahead of w = 10 at L = 60
# and 167 and behind it at L = 100 (125 against 136, on 58/47 against 68/46
# discordants, i.e. within noise), and never behind the stock table anywhere.
# With the garble-flagged messages in the pool w = 1000 reads 223 against
# 164, +59.
#
# LEAKAGE WAS CHECKED BEFORE BELIEVING THIS.  The corpus notes record
# re-sends and duplicate copies, and a copy in another fold would put the
# held-out message in its own training table.  Over the 34 clean messages
# the longest common substring between any two is 22 letters (one same-day
# pair), and most sharing pairs share a single 12-letter token.  Those are
# the recurring phrases the prior exists to learn, not copies.
#
# What that says: for this network, ~2 900 letters of its own traffic are a
# better model than 20 000 letters of Appendix C bent onto prose German, by
# 16 points of break50 at L=80.  The in-network caveat above applies with
# full force -- at w = 1000 there is nothing else in the table.
