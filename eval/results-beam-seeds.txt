# A BEAM ON T BEATS KICKED SEEDS AT SMALL BUDGETS AND LOSES AT LARGE ONES.
# At matched wall time it breaks 107 of 400 against 65 (z = +4.5) with 1 ms per
# key, and 213 against 236 (z = -2.4) with 8 ms.  The crossover sits at about
# 4 ms per key -- eight kicked seeds.
#
# AND THE SAME SHAPE APPEARS IN DEPTH once the arms are made to produce boards
# of the SAME SIZE (a 4-pair kick under -M, not the shipped 10-pair one): the
# beam is ahead at 4 and 5 plugs, level at 6, behind from 7.  Read the two
# matched sections below before the unmatched tables -- one headline here was
# an artefact of the size difference and is corrected there.
#
#   objs=$(ls src/[a-z]*.o | grep -vE 'main.o|enigma.o')
#   g++ -std=c++17 -O3 -pthread -Isrc -o /tmp/beam eval/proto_beam.cc $objs
#   /tmp/beam [keys] [kicked W] [beam W] [L] [apart] [plugs] [kick size] [-M]
#
# A PROTOTYPE, not shipped code.  It links against the repo's objects, so the
# kick (perturb_steckerbrett), both climbs (hillclimb<false>) and the scorers
# are the real ones.  The arms differ ONLY in how the seeds are produced.
#
#   arm A, what ships:  W random 10-plug kicks, each climbed to cap 4 under k.
#   arm B, the proposal: a width-W beam from the EMPTY board, one plug at a
#                        time to 4, scored on the T representation
#                        (eval/results-tseed-proto.txt) so nothing is decoded.
#
# Both then hand every seed to the SAME continuation: hillclimb<false> at cap
# 10 under -f.  400 keys per cell, L=100 telegraphic German, rotor key given,
# 10-pair board hidden, a trial counted broken at >= 50% of letters.
#
# ============================================================================
# MATCHED WALL TIME
# ============================================================================
#
#   A/B seeds   A brk   B brk    A ms/key  B ms/key  onlyA/onlyB      z
#      2/3         65     107        1.20      0.94       22/64     +4.53
#      4/7        109     156        2.10      2.10       33/80     +4.42
#      8/14       180     187        4.23      4.25       56/63     +0.64
#     16/27       236     213        8.46      8.18       57/34     -2.41
#     32/54       281     261       16.91     16.71       65/45     -1.91
#
#   z is McNemar on the paired per-key outcomes; positive favours the beam.
#   The beam width is chosen so the two arms cost the same, which is why B's
#   seed count is larger -- its seeds are ~5x cheaper to produce.
#
# THE BEAM FRONT-LOADS QUALITY, WHICH IS EXACTLY THE TRADE THE RAREFACTION WORK
# PREDICTS.  With few seeds you want the best ones and the beam supplies them;
# with many you want DIVERSE ones and the beam cannot, because it optimises
# score and its candidates crowd one region.  Distinct converged boards at
# equal seed count: 21.4 for the beam against 25.9 for kicks at W = 32.
#
# ============================================================================
# AT EQUAL SEED COUNT AND UNMATCHED SIZE THE BEAM LOSES -- SUPERSEDED BELOW
# ============================================================================
#
# KEPT AS THE MEASUREMENT THAT MISLED.  Arm A here is the SHIPPED kick, whose
# seeds carry 6.7 plugs against the beam's 4, so this compares two things at
# once.  Matched for size the d = 4 cell reverses (148 against 132 of 400).
# The section "TWO CONFOUNDS" below has the corrected form.
#
#   W       kicked brk / distinct     beam brk / distinct     (200 keys)
#    4          51 /  3.83                52 /  3.43
#    8          87 /  7.30                74 /  6.45
#   16         115 / 13.84                88 / 11.68
#   32         151 / 25.87               110 / 21.43
#
# The reading taken from this at the time -- "the beam's whole advantage is
# COST, not seed quality" -- is half right.  The cost advantage is real but
# smaller than the 5x here (most of that 5x is the shipped kick shedding six
# unwanted plugs, not the beam being fast), and at equal SIZE the beam's seeds
# are not worse at shallow depth.  What survives is the diversity ceiling.
#
# ============================================================================
# DISTINCT SEEDS IS THE WRONG MEASURE.  THE BEAM WINS IT AND LOSES ANYWAY.
# ============================================================================
#
# The tables above counted distinct CONTINUATIONS and never counted the seeds
# themselves, which left the obvious question unanswered.  Counted now, at 200
# keys, W = 8 both arms:
#
#   arm       breaks   plugs   distinct seeds   mean apart   distinct finals
#   kicked      87      6.70        7.86           17.10          7.30
#   beam        74      4.00        8.00            6.20          6.45
#
# THE BEAM RETURNS MORE DISTINCT SEEDS THAN KICKS DO -- 8.00 of 8 against 7.86,
# because `beamset` rejects a duplicate outright while two kicks can climb to
# the same board (which is exactly what --seed-dedup exists to skip).  So a
# distinct-seed count says the beam is the MORE diverse arm, and it is not.
#
# `apart` is the measure that works: the mean pairwise number of the 26 board
# entries on which two seeds differ.  17.10 for kicks against 6.20 for the
# beam, i.e. kicked seeds share almost nothing while beam seeds share most of
# their plugs.  That is STRUCTURAL: a width-W beam at depth 4 has W leaves but
# they hang off shared ancestors, so the level-1 and level-2 choices are common
# to most of the beam.  Kicks have no shared ancestry at all.  "Distinct" is
# satisfied by one plug of difference; "far apart" is not, and only the second
# predicts distinct basins after the continuation.
#
# ============================================================================
# TWO CONFOUNDS CHECKED.  ONE IS REAL AND REVERSES A HEADLINE.
# ============================================================================
#
# THE ARMS DO NOT PRODUCE THE SAME KIND OF BOARD.  Arm A's seeds carry 6.70
# plugs, not 4 -- without -M the cap blocks only ADDS, so a 10-plug kick
# climbed under cap 4 converges still holding ~6.7 (the effect the -M entry in
# CLAUDE.md documents).  The beam builds exactly 4 from empty.  So arm A is
# what the k4f10 schedule DOES and the depth-4 beam is what it SAYS, and the
# comparison confounded seed construction with seed size.
#
# DEEPENING THE BEAM ALONE DOES NOT CLOSE IT (200 keys, W = 8, shipped arm A =
# 87 breaks):
#
#   beam depth    4     5     6     7     8    10
#   breaks       74    77    70    65    72    68
#   mean apart  6.20  6.38  6.42  6.34  6.46  6.65
#   finals      6.45  6.00  5.59  5.28  5.03  4.66
#
# -- but that is still not a matched comparison, because it deepens ONE arm.
# The clean form is to shrink the KICK to the same size and turn -M on, so the
# cap becomes a strict descent target and arm A converges to exactly d plugs
# too.  THAT REVERSES THE HEADLINE AT SHALLOW DEPTH.  400 keys, W = 8 both
# arms, both producing exactly d plugs, McNemar z on the paired discordants:
#
#    d    A brk  A apart  A seedms   B brk  B apart  B seedms   only A/B     z
#    4     132    11.71     0.44      148     6.13     0.29      40/56    +1.63
#    5     147    13.94     0.64      160     6.27     0.34      43/56    +1.31
#    6     144    15.97     0.92      149     6.40     0.40      48/53    +0.50
#    7     156    17.60     1.20      140     6.28     0.44      61/45    -1.55
#    8     172    19.17     1.61      146     6.32     0.48      58/32    -2.74
#   10     167    21.07     2.65      140     6.46     0.54      56/29    -3.01
#
#   reference: the SHIPPED arm A -- kick 10, no -M, 6.71 plugs -- breaks 180 of
#   400 at 17.13 apart and 2.14 ms of seed time.
#
# SO "AT EQUAL SEED COUNT THE BEAM IS SIMPLY WORSE" WAS AN ARTEFACT OF THE SIZE
# CONFOUND, and the table above that says so is the unmatched one.  At d = 4
# and 5 the beam WINS on equal terms (neither cell reaches |z| = 2, so call it
# ahead-or-level rather than established); the crossover sits at d = 6 and only
# past it does the kicked arm win, significantly from d = 8.
#
# THE MECHANISM IS NOW VISIBLE AS A DIVERGENCE, not a level difference.  A
# KICKED ARM GETS MORE DIVERSE AS IT DEEPENS -- apart 11.71 -> 21.07, since a
# bigger kick scatters further -- WHILE THE BEAM STAYS FLAT AT ~6.3 AT EVERY
# DEPTH and its distinct finals FALL, 6.34 -> 4.47.  Both arms start from the
# same place at d = 4; the beam simply cannot follow.  A deeper beam commits
# harder to its shared prefix, so its extra plugs buy quality and cost
# coverage.
#
# THE COST GAP NARROWS THE SAME WAY.  A 4-pair kick under -M converges fast
# (0.44 ms against the shipped 10-pair kick's 2.14), so the beam's seed-cost
# advantage at matched size is 1.5x at d = 4, not the 7x the shipped comparison
# shows -- most of that 7x was the cost of shedding six unwanted plugs.  It
# widens again with depth (3.4x at d = 8) because the kicked climb pays for
# depth and the beam nearly does not.
#
# ============================================================================
# THE SEPARATION CONSTRAINT HELPS A LITTLE, AND ITS FIRST VERSION COULD NOT
# ============================================================================
#
# `apart` requires kept beam entries to differ in at least that many plugged
# letters.  Rejecting a near neighbour, or evicting a worse one, keeps W
# entries:
#
#   W = 16:  apart 0 -> 88 breaks,  apart 4 -> 92
#   W = 32:  apart 0 -> 110,        apart 4 -> 120
#
# AND IT HELPS EXACTLY IN PROPORTION TO THE APARTNESS IT BUYS, which is the
# check that turns the knob from a knob into evidence (200 keys, W = 16):
#
#   arm / setting     breaks    mean apart    distinct finals
#   beam apart 0        88          6.73           11.68
#   beam apart 4        92          8.26           12.20
#   kicked             115         17.20           13.84
#
# apart = 2 and 3 are INERT, byte-identical to 0, and the reason PREDICTS it
# rather than describing it: WITHIN A LEVEL EVERY CANDIDATE HAS THE SAME PLUG
# COUNT, which makes the distance skip values.  d = 1 is impossible for any two
# involutions (if position i differs, its partner must differ too); d = 2 is
# impossible at equal plug count, since it requires one board to hold exactly
# one plug the other lacks; so the smallest real separation is d = 3, two
# boards sharing one cabled letter -- (A,B) against (A,C).  apart = 4 is
# therefore the first threshold that can reject anything the duplicate check
# does not.  It moves apartness 6.73 -> 8.26 and
# breaks 88 -> 92, still half of the kicked arm's separation.  So the
# constraint works in the right direction and cannot reach far enough: it
# prunes within a beam whose candidates already share their ancestry.
#
# A FIRST VERSION FILTERED THE FINISHED BEAM instead, which could only SHRINK
# the seed count -- it lost breaks by returning fewer seeds and would have been
# reported as "diversity does not help".  It is a replacement rule now.
#
# apart >= 6 WAS DEGENERATE UNDER A FLAT THRESHOLD, and that was the harness
# again rather than the method: at level 1 a board holds one plug, so two
# candidates can differ in AT MOST 4 entries and a flat 6 rejects every pair,
# collapsing the beam to width 1.  The threshold now SCALES with the level --
# the argument is the value at the final level, apportioned linearly before it
# -- so a large setting is legal.  The section below sweeps it.
#
# ============================================================================
# RAISING IT DOES BUY DIVERSITY.  IT DOES NOT BUY BREAKS.
# ============================================================================
#
# The knob delivers exactly what it promises -- 400 keys, W = 8, depth 4, arm
# A size-matched (kick 4, -M), which returns 132 breaks at 7.89 seeds and
# 11.71 apart:
#
#   apart    0     4     5     6     8    10    12    14    16
#   breaks  148   155   137   136   131   104    93    93    69
#   dseeds 8.00  8.00  5.96  5.89  5.26  4.33  3.66  2.81  1.51
#   apart  6.13  7.12  8.85  9.39 10.62 11.89 12.56 13.97 15.65
#
# APARTNESS RISES MONOTONICALLY, 6.13 -> 15.65, so the beam CAN be made as
# diverse as the kicked arm and more.  At apart = 10 it reaches 11.89 against
# the kicked arm's 11.71 -- a dead heat on diversity -- and breaks 104 against
# 132.  THE DIVERSITY IS BOUGHT WITH SEEDS, ONE FOR ONE: the kept set stops
# filling (8.00 -> 1.51), because a candidate good enough to enter is now also
# required to be far from everything already kept.
#
# RAISING W DOES NOT BUY THEM BACK.  The fill saturates near W/2.6 rather than
# approaching W, since the constraint bites harder the fuller the set gets:
#
#   W        apart 0: breaks / dseeds        apart 10: breaks / dseeds
#    8            148 /  8.00                     104 /  4.33
#   16            179 / 16.00                     130 /  7.18
#   32            211 / 32.00                     174 / 12.64
#   64            256 / 64.00                     222 / 24.05
#
# AND AT MATCHED COMPUTE IT IS A SMALL LOSS, which is the number that decides
# it.  The constrained arm does win on breaks-per-SEED at large W -- 24.05
# seeds returning 222 breaks against 32.00 seeds returning 211, the rarefaction
# logic reasserting itself -- but the seeds are not what is paid for:
#
#   configuration          breaks    total ms/key    breaks per ms
#   W =  32, apart  0        211         9.61            21.9
#   W =  64, apart 10        222        10.86            20.4
#   W =  64, apart  0        256        19.82            12.9
#   W = 128, apart 10        261        25.89            10.1
#
# SO apart = 4 IS THE ONLY SETTING THAT PAYS, and the reason it is free is the
# parity argument above: it rejects only d = 3, two boards sharing one cabled
# letter, and such a candidate is readily replaced -- dseeds stays at 8.00.
# Every stronger setting binds, and binding costs more than the diversity is
# worth.
#
# THE CEILING IS COMBINATORIAL, NOT A TUNING FAILURE.  W boards pairwise
# disjoint at l plugs need 2lW distinct letters, so with 26 letters and l = 4
# no more than THREE fully-separated seeds exist at all.  A beam cannot be both
# wide and fully diverse; a kick can, because it is not required to be good.
#
# ============================================================================
# ONE HARNESS BUG WORTH RECORDING
# ============================================================================
#
# The first beam used a std::set<std::string> per level to de-duplicate, which
# allocated a 26-byte string for each of ~6000 candidates and made seed
# generation cost the SAME as the kicked climbs it exists to undercut -- 2.12
# against 2.20 ms.  That is an artefact of the harness, and reported as it
# stood it would have read as a property of the method ("no cheaper").  The
# kept set is at most W, so the common path is one compare against the worst
# kept; fixing it moved seed generation to 0.25 ms.  MEASURE THE THING, NOT THE
# BOOKKEEPING AROUND IT.
#
# ============================================================================
# SCOPE
# ============================================================================
#
# One length (L=100), one corpus, one machine mode, the plugboard tier with the
# rotor key GIVEN.  The beam starts from the EMPTY board every time, so it is
# deterministic per key -- it cannot be re-run for more seeds the way a kick
# can, which is the structural reason its width cannot grow indefinitely.
#
# NOT TESTED: a hybrid.  The obvious one is to take the beam's W seeds and
# then continue with kicks, which would front-load quality without capping
# diversity.  Nothing here measures it.
#
# NOT TESTED AT OTHER LENGTHS.  The T representation's speed advantage grows
# with L (2.7x at L=60, 23.6x at L=1000), so the crossover budget should move
# with length too -- at longer messages the beam's seeds are cheaper still
# relative to the continuation, which should push the crossover to the right.
