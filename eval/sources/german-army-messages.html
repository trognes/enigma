German Army Enigma Messages
Messages That We Have Failed to Break.

The cipher text messages below are messages from the German Army Collection that we failed to break when attacking these messages in 2003-2004. To our knowledge they have all been enciphered on the German Army 3-wheel Enigma machine. The reason they did not break was probably a combination of non-favorable plain text, problematic Stecker connections and, for some of them, too short messages.

The messages below are given in transcribed form more or less as they appear on the German message forms. We identify the messages by date, message number and the designator group which is the first cipher text group. The designator group is not part of the message and should be removed before trying to break the messages. When we store the cipher text of the messages in separate files we use the designator group as the file name. Red message numbers means incoming messages while blue message numbers are used for outgoing messages.

In the message header you will often find that the same tactical call sign, e.g. noa, is entered in both the Von (From) and An (To) fields. This is our way of transcribing the information from the original message forms. On the original forms the call sign is entered only once, but it is written behind a bracket enclosing both the Von and An fields. Why it is done so we do not know. One possible explanation is that the call sign refers to a radio network (NETZ) where the traffic would move in all directions between the participating stations.

For the non German speakers, here is a short explanation of some of the German terms used in the message header:

  • Aufgenommen am: = Received on:
  • Befordert am: = Sent on:
  • Uhr: = Time:
  • Durch: = By (operator):
  • Funkspruch Nr.: = Radio Message No.:
  • Von: = From:
  • An: = To:
  • Vermerke: = Remarks:
  • Absendende Stelle: = Transmitting Station:

For further information about our codebreaking project see our Web Portal: Breaking German Wehrmacht Ciphers.

Note: This message failed to break. It was first broken on 14 July 2026 
after the discovery of a number of ciphertext (Funkspruch) messages from 
another SS-Totenkopf radio station in the German Bundesarchiv's archive 
collections. The new message has an almost identical header, but because 
it is from another radio station in the network, it carries a different 
message number. It is number 55 in the blue outgoing series of messages, 
and is therefore possibly the original message. The new message carries 
the start position, abc, in the margin. The message header indicates a 
length of 92 letters, but the ciphertext is only 91 letters long, and 
the plaintext shows that this is most likely correct. The ciphertext 
of the new message differs significantly from the old message Nr. 81, 
which explains why this message failed to decipher into readable 
plaintext.
