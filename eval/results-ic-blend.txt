# Scale calibration (single instance, L90): lambda=1 and lambda=10 give
# BYTE-IDENTICAL output to lambda=0 on that instance; the term only starts
# changing decisions around lambda=40. Section 6.4's proposed sweep of
# {0,0.25,0.5,1} is entirely inert and would have produced a false negative.
# n=40 pilot at L70: lambda=80 -> -8.0pp, lambda=160 -> -27.7pp, so there is
# an optimum between 30 and 80.

# COMPUTE FAIRNESS (the confound this probe could have had): the blend adds a
# 26-bin histogram per score, so matched score_iter is not automatically matched
# wall time. Measured at -R 400, min of 3, L90 wehrmacht:
#   off .213s | lam=10 .209s | lam=20 .210s | lam=30 .205s
# i.e. within noise -- the histogram is cheap next to the gather-bound decode,
# and the one-pass implementation avoids a second decode. Both arms also run the
# same -R. So the gain is not bought with extra compute on either axis.
