# RANKING THE KICK BY k IS MEASURED DOWN: -3.9% OF BREAKS, z = -3.08.
# THE OFFLINE PROBE PREDICTED THE WRONG DIRECTION.
#
#   make
#   python3 eval/kick_rank_ab.py --trials 600 --length 167 \
#       --restarts 1 2 3 4 5 --temp 1 --seed 1
#
# --biased-random ranks its 325 single plugs by IC.  k (mono + lambda*L*IC)
# beats IC as the cap-stage pre-pass by 5.01pp, and the offline probe said k
# also ranks SINGLE PLUGS better at every length -- +9.9% more true plugs
# landed by the kick at L=167 (eval/results-kickrank.txt).  So the end-to-end
# run was expected to confirm it.  It did the opposite.
#
# ============================================================================
# 1. THE RESULT
# ============================================================================
#
# Paired, same trial in both arms -- same excerpt, same rotor key, same hidden
# 10-pair board, same T = 1 -- differing only by $ENIGMA_KICK_RANK.  Authentic
# HG Nord decrypts, L = 167, rotor key GIVEN, recommended recipe
# (-c -J --polish -f -l wehrmacht -S k4f10), 600 trials per cell.
#
#     R      IC       k    effect   onlyIC/onlyK      z   mean%IC  mean%k
#     1     321     303     -5.6%          89/71  -1.42     56.8    54.1
#     2     386     366     -5.2%          81/61  -1.68     66.8    64.0
#     3     418     408     -2.4%          68/58  -0.89     71.9    70.6
#     4     438     421     -3.9%          67/50  -1.57     75.1    72.5
#     5     454     440     -3.1%          63/49  -1.32     77.5    75.4
#
#   pooled  2017 -> 1938   -3.9%        368/289  z = -3.08
#
# NO SINGLE CELL RESOLVES, and the bands are what to read: five of five
# negative (P = 2^-5 = 3% under a fair coin) with a pooled z past 3.  Mean
# %-correct agrees in every cell, which is the graded, lower-variance signal.
#
# k also costs slightly MORE per key -- it computes the monogram half as well
# -- so at matched wall time rather than matched -R it would read a little
# worse still.  Not measured; the effect is small beside 3.9%.
#
# ============================================================================
# 2. THE OBVIOUS EXPLANATION IS WRONG
# ============================================================================
#
# This flag's own history says a kick cold enough to LAND on the joint argmax
# loses to one merely biased toward it -- the four-plug IC optimum is a decoy
# that outscores the truth.  So the natural reading is that k is simply
# SHARPER at the same temperature, and needs a warmer one.
#
# MEASURED, AND IT IS NOT.  Extending the probe to report how concentrated the
# softmax weights are, at T = 1, L = 167, 300 keys:
#
#     model   mass on the top 10 of 325   effective pool size exp(H)
#        IC                       24.0%                       174
#         k                       24.1%                       175
#
# Identical to within a tenth of a point.  z-scoring equalises the SPREAD, and
# it turns out to equalise the shape here too: the two kicks draw from
# equally-sized effective pools.  So "k is colder" is refuted, and a
# temperature retune is not the fix.
#
# ============================================================================
# 3. WHAT IS LEFT, AND IT IS A HYPOTHESIS
# ============================================================================
#
# k lands MORE TRUE PLUGS (0.398 against 0.362 per 4-pair kick) and BREAKS
# FEWER MESSAGES.  Those two facts have to be reconciled and this run does not
# do it.  The candidate worth testing:
#
#   THE KICK MAY WANT TO BE DECORRELATED FROM THE CLIMB'S OWN OBJECTIVE.  The
#   pre-pass in this recipe IS k (-S k4f10).  A k-ranked kick therefore seeds
#   the climb into basins the k pre-pass already favours, so the two agree and
#   the kick adds little; IC is a partly INDEPENDENT statistic, and its
#   disagreements are exactly where a kick has something to contribute.  On
#   that reading, a better kick model is not a better one but a different one.
#
#   It predicts a clean test: run the same A/B under an `i4f10` pre-pass.  If
#   redundancy is the mechanism, k-ranking should stop losing there -- because
#   it is then the decorrelated one -- and IC-ranking should be the redundant
#   arm.  NOT RUN.
#
# A second, duller possibility that the same test does not separate: the extra
# true plugs k finds may be ones the climb recovers unaided, so landing them
# in the kick buys nothing while displacing plugs that were worth seeding.
#
# ============================================================================
# 4. THE LESSON ABOUT PROBES, WHICH IS THE DURABLE PART
# ============================================================================
#
# CLAUDE.md already records that the mono+IC AUC probe "predicts the ORDERING
# and not the magnitude".  THIS IS WORSE THAN THAT: the probe got the ORDERING
# wrong.  It was not a bad probe -- it measured exactly what it claimed, true
# plugs landed by the shipped sampler, paired against the same random stream,
# and k really does land more.  The failure is that the quantity is not the
# objective: more true plugs in a seed is not more breaks, because the kick's
# job is where it puts the climb, not how right it already is.
#
# So the note in CLAUDE.md should read that an offline probe justifies
# STARTING a recovery run and is not evidence of the sign of one, in either
# direction.  This is the second time in this feature's history that a seeding
# idea looked good offline and lost end to end (the beam over the same scores
# was the first, eval/results-beam-seeds.txt).
#
# ============================================================================
