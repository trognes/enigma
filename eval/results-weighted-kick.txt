# A WEIGHTED KICK IS A NULL.  Biasing the restart kick toward plugs that score
# well on their own raises the seeds' true-plug count by 25% and changes the
# break rate by nothing: 1043 of 3200 against the uniform kick's 1052,
# z = -0.34.  The lever works and does not convert.
#
#   objs=$(ls src/[a-z]*.o | grep -vE 'main.o|enigma.o')
#   g++ -std=c++17 -O3 -pthread -Isrc -o /tmp/wkick eval/proto_wkick.cc $objs
#   /tmp/wkick [keys] [restarts] [L] [temperature] [kick] [-M] [cap]
#
#   eval/proto_plugrank.cc measures the mechanism this rests on.
#
# ============================================================================
# THE IDEA
# ============================================================================
#
# The kick that starts every restart draws its plug pairs UNIFORMLY.  But all
# 325 single-plug boards can be scored under IC in ~15 us per key on the T
# representation (eval/results-tseed-proto.txt), so the kick could instead draw
# with probability exp(z / T) over those scores -- a softmax on the z-score of
# each plug's own IC.  T -> infinity is the uniform kick, T -> 0 is the greedy
# argmax, and everything between is a continuous dial.
#
# THE MOTIVATION WAS A SPECIFIC DIAGNOSIS.  eval/results-beam-seeds.txt found a
# beam over the same scores losing at every budget past ~8 seeds, and blamed
# SHARED ANCESTRY: a width-W beam's leaves hang off common prefixes, so its
# seeds sit 6.1 apart against the kick's 17.4, and diversity collapses rather
# than degrading.  A weighted kick has NO ancestry -- every seed is an
# independent draw -- so it was the clean test of that diagnosis.
#
# ============================================================================
# THE PRECONDITION HOLDS: TRUE PLUGS ARE ENRICHED AT THE TOP
# ============================================================================
#
# L = 100, 100 keys, 10-pair board hidden, rotor key given:
#
#   mean rank of a true plug        109.9 of 325     (chance 163.0)
#   true plugs in the top 10         12.1%           (chance  3.1%)   3.9x
#   true plugs in the top 25         23.6%           (chance  7.7%)   3.1x
#   true plugs in the top 50         37.9%           (chance 15.4%)   2.5x
#   true plugs in the top 100        54.1%           (chance 30.8%)   1.8x
#
# So a single plug's own IC score really does carry information about whether
# that cable is in the board.  THAT IS NOT IN TENSION with the finding that the
# joint four-plug IC argmax is wrong (eval/results-seed-landscape.txt): the
# MARGINAL signal is what is being sampled, and sampling is precisely what
# avoids committing to the bad joint argmax.
#
# And the sampler delivers what the enrichment predicts.  Expected true plugs
# in a 4-plug kick, before any climbing:
#
#   weighting       true plugs / 4    vs uniform    apart
#   uniform             0.124            1.00x      13.44
#   softmax T=4         0.145            1.17x      13.41
#   softmax T=2         0.175            1.41x      13.29
#   softmax T=1         0.263            2.11x      12.72
#   softmax T=0.5       0.441            3.55x      10.34
#   softmax T=0.25      0.583            4.70x       6.42
#
# ============================================================================
# END TO END IT IS A NULL
# ============================================================================
#
# Arm A is perturb_steckerbrett(), the shipped uniform kick; arm B draws the
# same number of pairs from the softmax.  EVERYTHING DOWNSTREAM IS IDENTICAL --
# the same cap-4 climb under k makes the seed, the same hillclimb<false> at cap
# 10 under -f is the continuation, the same keys in the same order.  400 keys,
# R = 8, L = 100, kick 10, no -M.  Arm A is constant across the rows by
# construction:
#
#   T        A brk   B brk   B true/seed   B apart   onlyA/B      z
#   0 (ctrl)   128     127      0.94        17.28     42/41     -0.11
#   4          128     105      0.98        16.63     50/27     -2.62
#   2          128     125      1.05        16.13     40/37     -0.34
#   1          128     135      1.14        15.34     44/51     +0.72
#   0.5        128     119      1.28        13.95     49/40     -0.95
#   0.25       128     105      1.33        12.34     54/31     -2.49
#
#   T = 0 IS THE CONTROL AND IT IS CLEAN: with the weights flat, arm B is arm A
#   with a different RNG stream, and it matches on every column (127 against
#   128, apart 17.28 against 17.25).  A harness that failed here would make the
#   rest unreadable.
#
# THE ONLY POSITIVE CELL DID NOT SURVIVE POWER.  T = 1 read +0.72 at 400 keys;
# at 3200 keys it is 1043 against 1052, z = -0.34, and T = 1.5 reads +0.71 --
# i.e. the sign wanders and the magnitude does not grow.  Both are nulls:
#
#   T      A brk of 3200   B brk   B true/seed   B apart   onlyA/B      z
#   1          1052         1043      1.20        15.34    346/337    -0.34
#   1.5        1052         1071      1.13        15.94    345/364    +0.71
#
# THE MECHANISM WORKED THROUGHOUT, which is what makes this a real negative
# rather than a failed implementation.  Seed true-plug count rises monotonically
# with the bias (+25% at T = 1 after the climb, +43% at T = 0.25) and apartness
# falls monotonically (-11%, -29%).  The dial did exactly what it was built to
# do; the break rate simply does not respond to it.
#
# NOR IS IT A COMPUTE ARTEFACT.  The weighted arm is slightly CHEAPER in total
# (0.92-0.97x of arm A's ms/key at every temperature) because its seeds
# converge faster, so it is not paying for the 325-plug scan out of the
# restart budget.
#
# ============================================================================
# WHAT THIS REFUTES
# ============================================================================
#
# THE SHARED-ANCESTRY DIAGNOSIS OF THE BEAM'S FAILURE IS WRONG, or at least
# insufficient.  That diagnosis predicted a sampler with independent draws and
# graceful diversity decay would convert where the beam did not.  This is that
# sampler -- at T = 1 it holds 15.34 apartness against the beam's 6.12, well
# inside the kick's own 17.3 -- and it converts nothing.
#
# So it is not HOW the seeds are correlated.  A seed carrying 1.20 true plugs
# instead of 0.96 does not land the f10 continuation in a different basin often
# enough to matter, whatever the seeds' relationship to each other.  That is
# consistent with the standing result in CLAUDE.md that the hard residual is
# WRONG-BASIN failure which only a fresh restart can relocate -- and it now has
# a second, independent line of evidence: two different ways of making seeds
# better by their own score, both null-to-negative end to end.
#
# TAKEN WITH THE BEAM, THE SEED-QUALITY LINE IS CLOSED at this scale.  What is
# left unmeasured is whether the single-plug ranking is useful for something
# other than seeding -- as a move ORDER inside the climb, say, where -J already
# shows dynamic ordering is worth 2-6pp.
#
# ============================================================================
# THE SAMPLER: RENORMALISING IS UNNECESSARY
# ============================================================================
#
# Drawing from the full 325 and REDRAWING on a conflict is the same
# distribution as renormalising over the still-legal pairs after each pick --
# rejection conditions on legality, which is what renormalisation computes.
# Measured side by side, the two agree to sampling noise at every temperature,
# so the choice is pure cost:
#
#   weighting       renorm true/4   reject true/4   draws/kick   gave up
#   uniform             0.124           0.120          5.30        0.0%
#   softmax T=4         0.141           0.142          5.33        0.0%
#   softmax T=2         0.171           0.173          5.42        0.0%
#   softmax T=1         0.250           0.252          5.99        0.0%
#   softmax T=0.5       0.442           0.439         19.54        0.0%
#   softmax T=0.25      0.616           0.595        399.04       11.2%
#
# THE FLOOR OF 5.30 DRAWS IS COMBINATORICS, not weighting: after k picks,
# C(26,2) - C(26-2k,2) pairs are dead, so the four picks succeed with
# probability 1, 0.849, 0.711, 0.585.  With a prefix sum built once per key a
# draw is a binary search over 325, so a kick costs ~50 operations against
# renormalisation's 4 x 325 = 1300.
#
# IT BREAKS DOWN AT T <= 0.5, and the hazard is silent truncation rather than
# cost: at T = 0.25 the mass concentrates enough that 11% of kicks hit the
# attempt guard and return FEWER than four pairs, which changes what is being
# measured rather than how fast it runs.  proto_wkick.cc therefore falls back
# to an exact renormalised pass when rejection fails, so a cold temperature is
# slow but never short.
#
# ============================================================================
# SCOPE
# ============================================================================
#
# One length (L = 100), one corpus, R = 8, kick 10 with no -M -- the shipped
# configuration.  IC only as the ranking model; the shipped pre-pass is k
# (mono + lambda*L*IC) and the same T build yields both, so a mono or blended
# ranking is cheap to try and was not.  Nothing here varies R, and the beam
# work found the seed/diversity trade to be budget-dependent, so a null at
# R = 8 does not settle R = 1000.
