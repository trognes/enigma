# Scoring failures at 40-100 letters, and whether a SECOND message on the
# same day key rescues them.  eval/joint_score_gain.py --trials 800, seed 1,
# -R 8, recipe -f -S i4f10 -J --polish -l wehrmacht, true rotor key given.
# CLASSIFIED WITH THE FUSED MODEL -- the one the climb optimises.
#
52 authentic telegraphic plaintexts, model 'wehrmacht', real climb at -R 8

    L  trials    exact    search   scoring  of miss     rescued
   40     800     0.1%     11.8%     88.1%      88%    677/705
   60     800     1.1%     49.4%     49.5%      50%    395/396
   80     800     8.6%     69.8%     21.6%      24%    173/173
  100     800    16.5%     77.0%      6.5%       8%      52/52

  exact   = the climb recovered the true board
  search  = climb missed, what it found scores LOWER  (more restarts help)
  scoring = climb missed, what it found scores HIGHER (no search helps)
  of miss = scoring failures as a share of NON-EXACT trials
  rescued = of those, how many the true board wins back once message 2 is
            added, its start DERIVED per board under test
#
# HOW COMMON: 88% of MISSES at L=40, 50% at 60, 24% at 80, 8% at 100.
#
# An earlier version classified with a plain Python quadgram score while the
# climb maximised FUSED. That is not merely a different metric but a BIASED
# one: a board the climb converged on is by construction competitive on
# fused, so quadgrams understate how often it beats the truth. It read 19%
# of misses at L=60 where the correct figure is 50%. Superseded -- classify
# with the model the search uses.
#
# WHY THE RESCUE WORKS: the true board derives the CORRECT start for message
# 2 and collects a full German decrypt, while a climbed impostor derives a
# wrong one and collects noise. Not the sqrt(2) a plain joint score gives --
# an asymmetry. Verified MODEL-INDEPENDENT: re-checked under fused it is
# 209/210 and 75/75 at L=60/80, where quadgrams also gave ~100%.
#
# WHY IT DEGRADES AT 40-60: message 2 is a FIXED quantity of evidence and a
# scoring failure can exceed it. Probed at L=40, ZERO of 9 unrescued cases
# had the impostor deriving a correct start2 -- all were cases where its
# message-1 lead exceeded what a 40-letter German decrypt is worth.
#
# SCOPE: the climb runs at the TRUE rotor key, isolating scoring from search
# by construction. Exact recovery (0.1/1.1/8.6/16.5%) brackets CLAUDE.md's
# 12.0% at L=82. Says nothing about trials where the climb never reaches the
# board.
#
# ============================================================================
# WHY THIS CONTRADICTS THE REPO'S DOCUMENTED ~1% SCORING FLOOR
# ============================================================================
#
# CLAUDE.md records a ~1% scoring-failure floor and "at short lengths the
# residual is ~99% search failure"; ENHANCEMENTS item 2 records "5-10% at L40,
# 0 elsewhere".  Those come from `make crackquality`, whose corpus is 477
# characters of ENGLISH PROSE.  They do not transfer.
#
# Two variables move the split, isolated one at a time (200 trials each, L=40):
#
#   plaintext / language                    search    scoring
#   English prose      -q -l english        100.0%       0.0%
#   telegraphic German -q -l wehrmacht       44.0%      56.0%
#
#   model, on telegraphic German            search    scoring
#   -q                                       44.0%      56.0%
#   -f -S i4f10 -J --polish                  10.0%      90.0%
#
# NOT the garbled decrypts in the pool: restricting to clean plaintexts gives
# 89.5% against 90.5% at L=40, i.e. no effect.
#
# Both directions are real.  A STRONGER SEARCH MAKES IT WORSE: it reaches
# boards a weak climb never found, and at 40 letters with ten free plug pairs
# those boards overfit.  crackquality on its own English corpus shows the same
# sign, 0% -> 2%, when -J --polish -R 8 is added.
#
# Telegraphic German is flatter to score than prose -- X separators,
# spelled-out numbers, a small vocabulary -- so the true plaintext stands less
# far above a wrong decrypt.  That is the same style dependence CLAUDE.md
# already records for the wehrmacht tables (+20.9pp on real messages, -10.2pp
# on prose) and for SA-vs-greedy; this is another instance of it.
#
# So "how much of the residual is scoring" is a property of the CORPUS and the
# SEARCH STRENGTH, not of message length alone, and any single figure for it
# needs both stated.
